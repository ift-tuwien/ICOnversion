# ICOnversion

- Convert 16 bit ADC values of the [ICOtronic](https://www.mytoolit.com/ICOtronic/) system of to physical values

- Inputs:
  - 16 Bit integer ADC value
  - Sensor Information

- Output:
  - Float Value
